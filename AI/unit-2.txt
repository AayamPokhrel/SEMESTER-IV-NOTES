 Problem Solving by Searching
Problem solving in AI is a systematic search through a range of possible action in order to reach some predefined goals or solutions.
There are four general states in problem solving which are as follows:
Goal formulation: A goal is a agent that the agent is trying to reach
Problem formulation:  the process of deciding what actions and states and goal to consider
search method: It determines possible sequence of actions and choose the best one
Execute:it provides the solution to perform actions
(state space: collection of all states)

Searching:
problem formulation : In AI it is the process of defining problem in a way that a computer can understand and solve it using AI techniquies-especially search algorithms.

- Component of problem formulation:
-Initial state: the starting point of the problem
- state spaces: all possible states reachable from the initial state
-actions: legal movees or operations that can be performed
- transition model: describes what results from performing an aciton in a state
-goal test: check whether a given state is a goal state
-path cost:(optional):A numeric cost for a path, used in optimization.
(Transition model: a to b or b to a )
