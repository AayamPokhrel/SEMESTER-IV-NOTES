# Semester IV Notes

This repository contains my Semester IV study materials, organized by subject. It includes chapter-wise notes, reference PDFs, presentation slides, and lab programs for quick revision and coursework practice.

## Subjects Covered

- **Artificial Intelligence**: Comprehensive Markdown notes for introduction to AI, intelligent agents, search techniques, and knowledge representation.
- **Database Management System**: Unit-wise PDF notes on database users, system concepts, and architecture.
- **Networking**: PDF notes and presentation slides covering computer network fundamentals, physical layer, data link layer, network layer, and IP addressing.
- **Operating System**: Chapter PDFs, process scheduling notes, and C lab programs for system calls and scheduling concepts.
- **Theory of Computation**: Lab materials and Rust programs related to automata and formal language exercises.

## Purpose

The goal of this repository is to keep Semester IV academic resources in one place so they are easy to review, update, and reuse while preparing for exams, assignments, and lab work.

- Markdown files are intended for readable, editable notes.
